# Gnana Varshini Birthday Website 💗

Created by Tejaswini.

## How to open it

1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
   - If you have the VS Code Live Server extension, right-click `index.html`
     and choose **Open with Live Server**.

## Easy customization

Search inside `index.html` for:
- "Happy Birthday"
- the birthday letter
- photo captions

You can edit the text without changing the JavaScript.

The site uses a tiny browser-generated chime for button interactions, so no music file is required.
